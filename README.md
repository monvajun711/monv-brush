# 魔女刷子（monv-brush）

将用户有权处理的 Word、PDF、Markdown、TXT、RTF、HTML、演示文稿或表格，保真导出为 UTF-8 纯文本文件。尽量保留标题、段落、列表、引用和表格的可读结构，同时不复制文档元数据、批注、修订、隐藏文字、嵌入对象和不可见排版字符。

## 适用场景

- 文档归档、跨软件迁移、内容备份和纯文本交付。
- 需要将扫描件或常规 PDF 的文字安全提取为可编辑文本。
- 需要清除来源文件中的文档级属性和隐藏内容，但保留可读文本结构。

## 输出约定

- UTF-8、无 BOM、LF 换行的 `.txt`。
- 标题独立成段，正文段落间保留一个空行。
- 列表使用 `-` 或 `1.`，表格使用制表符分隔单元格。
- 扫描件会在必要时 OCR，并说明 OCR 可能存在的识别误差。

## 边界

本技能用于格式转换、隐私卫生和内容迁移，不用于规避 AI 内容检测，也不保证任何检测器的结果。它不会改变正文的作者身份、事实准确性或原创性；用户应按目标平台、机构或出版方的规则标注和使用 AI 协助内容。
